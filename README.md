# DevBrowser

Web geliştiriciler için tarayıcı. Bu depoda yalnızca kurulum dosyaları ve güncellemeler bulunur.

## İndirme

Son sürüm: [Releases](https://github.com/SariSelim/devbrowser-releases/releases/latest) sayfasındaki `.dmg` dosyası (macOS, Apple Silicon).

## Kurulum

1. `.dmg` dosyasını aç, DevBrowser'ı Uygulamalar klasörüne sürükle.
2. Uygulama henüz Apple tarafından imzalanmadığı için ilk açılışta macOS uyarı verir: Sistem Ayarları → Gizlilik ve Güvenlik bölümünde "Yine de Aç"a bas (eski macOS sürümlerinde uygulamaya sağ tıklayıp "Aç").
3. Sonraki sürümler uygulamanın içinden kendiliğinden güncellenir.
